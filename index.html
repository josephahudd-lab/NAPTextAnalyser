Keyword Heuristics Applied for Matrix Dimensions

In Keyword Scan Mode, extracted facts are classified across the 10 policy dimensions using automated word-stem heuristics:

Timing: "prevent/future" → Anticipatory; else Reactive
Depth: "systemic/transform" → Transformational; else Incremental
Governance: "council/local/city" → Local; "business/household" → Household; else National
Readiness: "shovel/ready/underway" → Shovel-ready; else Developmental
Robustness: "lock-in/fixed" → Locked-in; else Flexible/modular
Spatial Scope: "catchment/basin/region" → Catchment; else Site-Specific
Cost-Benefit: "cost/benefit/quantif" → Quantifiable; else Complex
Function: "capacity/train/study" → Capacity; else Direct Action
Strategy Type: "long-term/2040/2050" → Long term; else Short term
